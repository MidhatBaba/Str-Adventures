
 # Str Adventures (Travel Platform using MERN Stack)

Introduction Str Adventures is an innovative platform designed for trekking enthusiasts, offering a comprehensive solution for booking and managing trekking adventures. With a focus on a user-friendly experience, Str Adventures integrates modern technologies to provide seamless navigation, secure bookings, and detailed trekking information. The platform's sleek design and advanced features ensure that your adventure planning is smooth and enjoyable.

# Tech Stack
React.js: For building the user interface.

Node.js: For server-side scripting.

Express.js: For building the server and handling routes.

MongoDB: For storing and managing data.

Mantine: For UI components and styling.

JWT (JSON Web Token): For secure authentication.

# Quick Start
Follow these steps to get Str Adventures up and running on your local machine.

## Prerequisites
Ensure that you have the following installed on your system:

- **Node.js**
- **Git** 
- **npm or yarn** 

## Installation

- **Clone the Repository**:
Open your terminal and run the following command:
git clone https://github.com/MidhatBaba/Str-Adventures.git
- **Navigate into the project directory**:
cd str-adventures
- **Install Dependencies**:
Install the required packages using npm or yarn:
npm install
Or, yarn install

## Setup Environment Variables
Create a .env file in the root directory and set up the necessary environment variables.
- **App Config**:
REACT_APP_BASE_URL=http://localhost:3000
- **Authentication**:
JWT_SECRET=your_jwt_secret**_key
- **Database**:
MONGO_URI=your_mongo_database_uri

## Running the Application
Run the Development Server:
Use the following command to start the development server:
npm start


## Access the Application:
Open your browser and navigate to http://localhost:3000 to explore the Str Adventures platform.
